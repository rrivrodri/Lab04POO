# Laboratorio 4 - Polimorfismo: Cooperativa AcopioGT
Curso: CC2008 Programación Orientada a Objetos - Universidad del Valle de Guatemala (UVG)

## Descripción
Aplicación de consola en Java que implementa una solución basada en interfaces, clases abstractas y polimorfismo para la gestión de lotes, bodegas, pre-liquidaciones, despachos y reportes de la cooperativa AcopioGT.

## Instrucciones para compilar y ejecutar
1. Asegúrate de tener instalado Java JDK en tu computadora.
2. Abre tu terminal o consola en la carpeta raíz del proyecto.
3. Compila todos los archivos fuente con el comando:
   ```bash
   javac *.java
